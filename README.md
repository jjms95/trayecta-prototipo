# Trayecta · Prototipo navegable (Usabilidad – Parcial 2, Grupo 1, Universidad del Quindío)

Nombre provisional. Prototipo HTML autocontenido (sin APIs ni claves; mapa SVG estilizado de Armenia).

## Cómo abrir
- En línea: https://jjms95.github.io/trayecta-prototipo/
- Sin conexión: abrir `index.html` en Chrome/Edge/Firefox (doble clic).
- Saltar a una pantalla: `index.html#s016` (o el selector de la izquierda).
- Tecla `?` o botón «RQ» del teléfono: muestra el ID de pantalla (UI-xxx) y los RQ que cubre.
- Modo de impresión (una pantalla por página): `index.html?print&s=s016`.

## PDF tipo «Prototipo Navegable» (formato del ejemplo BetPrimeCOL)
`Prototipo_Navegable_Trayecta.pdf`: 42 páginas de 430×932 pt, una pantalla por página, en el orden del flujo.
